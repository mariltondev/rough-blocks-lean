This repository provides a complete Lean 4 formalization of the *RoughBlocks* theorem on $m$-rough numbers near $m^2$.  
It includes the analytical core (`Heavy`), the external certified bridge (`External`), and the stable public interface (`Light`).

The **priority** is to keep the **Light** layer stable and auditable, with Lean proofs that rely only on system axioms (`propext`, `Classical.choice`, `Quot.sound`).

**Main result:** for all $m \ge 10^6$ and $x \le 8$,  
each block $K_x = \{m^2 + xm + 1, \dots, m^2 + (x{+}1)m\}$  
contains at least one $m$-rough number ($P^-(n) > m$).

## Summary
We show that, for every $m \ge 10^6$ and each $x \in \{0,\dots,8\}$, the block
$K_x=\{m^2+xm+1,\dots,m^2+(x+1)m\}$ contains at least one $m$‑rough number
($P^-(n)>m$). The proof combines the Buchstab identity and function $\omega$ with
the explicit Mertens form via Abel summation, yielding a uniform local lemma on
short intervals $[X,X+Y]$, com $X\in[y^2,y^3]$ e $y\le Y\le 2y$:

![Inequality](docs/img/formula01.svg)

With effective constants $C_0\le 2$, $C_1\le 4{,}4$, and $C_2=100$. We treat the edge case $X=y^2$
separately and remove boundary terms by the convention $\omega(u)=0$ for $0<u<1$.
Applying the local lemma with $y=Y=m$ and $X=m^2+xm$ yields the result for each $K_x$.

With the current constants, **numerical computations suggest** the same argument would already work from
$m\ge 18{,}794$; however, in this repository we **formally certify** $m\ge 10^6$ and cover $2\le m<10^6$
via a **reproducible** computational sweep (code, logs, and instructions available
[here](https://doi.org/10.5281/zenodo.17137291)).

### Integration with the Lean formalization and certificates

- **Finite range $2 \le m < 10^6$:** encapsulated by a single axiom
  `RoughBlocks.Light.budget_verified_by_scan`, supported by deterministic sieving
  (artifacts at [Zenodo — DOI: 10.5281/zenodo.17137291](https://doi.org/10.5281/zenodo.17137291)).

- **Asymptotic range $m \ge 10^6$:** the “bridge” comparing the analytical lower bound $LB(m,x)$
  with the actual count in the block $K_x$ is validated **uniformly** by a Julia certificate
  with interval arithmetic (256 bits), stored at
  `certs/uniform-bridge-ge-1e6.json` and generated by
  `external/julia/uniform_bridge_certificate.jl`. This certificate is imported in Lean by the axiom
  `RoughBlocks.External.bridge_ge_1e6_uniform`.

## Introduction

We study $m$‑rough numbers (i.e., $P^-(n)>m$) in short windows near $m^2$. This repository isolates the technical core that underpins a broader program — henceforth nicknamed “[`MariltonCR’s conjecture of nested primes`](https://doi.org/10.5281/zenodo.16734582)”. The present work is entirely *unconditional*: we prove a uniform local result that guarantees, for large $m$, the presence of an $m$‑rough in each of nine consecutive blocks of length $m$ immediately to the right of $m^2$.

In parallel work, we develop combinatorial and sieve implications of this framework to resolve classic conjectures: **Legendre’s hypothesis**, **Oppermann’s conjecture**, **Brocard’s conjecture** (in the form “$\ge 4$ primes between $n^2$ and $(n{+}1)^2$”), the **strong Goldbach conjecture** (conditional on reinforced versions of the program), and we rederive **Bertrand’s postulate** as a corollary. We also open a line of study connecting these techniques to sieve heuristics under the **Generalized Riemann Hypothesis (GRH)**.

These goals are deliberately ambitious: we have already presented them as a research roadmap, and there are links to this repository. Here we deliver the first technical brick — a local theorem with explicit constants — upon which subsequent steps are being built in separate preprints, with periodic updates.

## 🚀 Quick start (build)

Update dependencies and cache:
```bash
lake update && lake exe cache get
```

Build **only** what exists in the current repository:
```bash
# External (uniform certificate ≥ 1e6)
lake build RoughBlocks.External.BridgeUniform

# Heavy (core used by Light)
lake build RoughBlocks.Heavy.Numeric
lake build RoughBlocks.Heavy.Buchstab

# Light (facade + spec/audit)
lake build RoughBlocks.Light.Export RoughBlocks.Light.Spec

# API sanity (sentinel file; builds silently)
lake build RoughBlocks.Check
```

Full audit via script:
```bash
chmod +x scripts/ci-local.sh      # first time
./scripts/ci-local.sh             # default run (Light + Heavy best-effort)

# useful variants:
./scripts/ci-local.sh --light
./scripts/ci-local.sh --heavy
./scripts/ci-local.sh --no-cache
./scripts/ci-local.sh --no-scratch
```

## 🧰 Public API (Light layer)

Import the facade and use qualified names from the **Light** namespace:

```lean
import RoughBlocks.Light.Export

-- Use qualified names (recommended):
#check RoughBlocks.Light.LB
#check RoughBlocks.Light.margin
#check RoughBlocks.Light.marginR
#check RoughBlocks.Light.budget_conservative_formal
#check RoughBlocks.Light.main_theorem_ge_1e6
```

**Ready-to-use theorem** (exposed by `Light.Export`):

```lean
theorem RoughBlocks.Light.main_theorem_ge_1e6
  {m x : ℕ} (hm : 1_000_000 ≤ m) (hx : x ≤ 8) :
  RoughBlocks.Light.LB m x ≥ 1
```

**“Sanity” example** (compact):

```lean
import RoughBlocks.Light.Export

example {m x : ℕ} (hm : 1_000_000 ≤ m) (hx : x ≤ 8) :
    RoughBlocks.Light.LB m x ≥ 1 :=
  RoughBlocks.Light.main_theorem_ge_1e6 (m:=m) (x:=x) hm hx
```

> The Light layer **reexports** symbols proved in Heavy. Client code **must not**
> import `RoughBlocks.Heavy.*` directly — keep the encapsulation intact.

### Note

This project uses **two reproducible external dependencies**; everything else is proved internally in Lean, using only the “system” axioms (`propext`, `Classical.choice`, `Quot.sound`).

- **Finite range $2 \le m < 10^6$.**  
  Encapsulated by the axixom `RoughBlocks.Light.budget_verified_by_scan`
  (file `RoughBlocks/Light/Existence.lean`), supported by deterministic sieving
  (code, logs, and instructions at [Zenodo — DOI: 10.5281/zenodo.17137291](https://doi.org/10.5281/zenodo.17137291)).  
  In particular, for $2 \le m < 10^6$ and $0 \le x \le 8$, we have $\mathrm{LB}(m,x) \ge 1$.

- **Asymptotic range $m \ge 10^6$.**  
  The “bridge” comparing the analytical lower bound $LB(m,x)$ with the actual count in the block $K_x$
  is validated **uniformly** via the axixom `RoughBlocks.External.bridge_ge_1e6_uniform`
  (file `RoughBlocks/External/BridgeUniform.lean`), instantiated by a Julia certificate with
  256‑bit interval arithmetic, stored at `certs/uniform-bridge-ge-1e6.json`
  and generated by `external/julia/uniform_bridge_certificate.jl`.

## Paper ↔ Lean map (1×1)

| Concept | LaTeX (stub) | Lean (type) |
|---|---|---|
| "n is m-rough (every prime of n is > m)" | mRough(m,n) | `RoughBlocks.mRough m n : Prop` |
| Block K(m,x) | {m^2 + xm + 1, ..., m^2 + (x+1)m} | `RoughBlocks.K m x : Finset ℕ` |
| "K has some m-rough" | ∃ n ∈ K(m,x): mRough(m,n) | `RoughBlocks.BlockHasMRough m x : Prop` |
| Lower bound | LB(m,x) ≥ 1 (conditions on m,x) | `RoughBlocks.Light.LB m x ≥ 1` *(re-exported in `Light.Export`)* |
| Monotonicity (example) | Φ_p(N1) ≤ Φ_p(N2) if N1 ≤ N2 | `PhiGE_mono_in_X p : Monotone (fun N => PhiGE N p)` |
| Buchstab (window) | ∑_p (Φ((X+Y)/p) - Φ(X/p)) | see lemmas in `Heavy/Buchstab/Core` and `Heavy/WindowLink/Core` *(see also `Heavy/Identity.lean`)* |
> Note: Lean notation uses `Nat`, `Finset`, and `BigOperators` from `mathlib`.  
> The $\mathbb{R}$ versions arise via coercion (`Nat.cast_*`) combined with monotonicity.

## 🧭 API stability policy

- **Light** is the **official facade** (stable public surface).  
  - We guarantee **backward compatibility** within the same major version for names under `RoughBlocks.Light.*`.
  - API breaks happen only in **major releases** and will be documented in the release notes.

- **Heavy** (`RoughBlocks.Heavy.*`) and **External** (`RoughBlocks.External.*`) are **internal details**.  
  - Clients **should not** import them directly. These layers may change without notice.

- `RoughBlocks.lean` is **minimal** (imports only `Defs` + `Light.Export`) and adds no extra API.  
  - Always use the facade: `import RoughBlocks.Light.Export`.

- `Light/Spec.lean` is **audit‑only** (`#print axioms`) and **not** part of the public API.

- **Deprecations** in the Light layer will be announced with a transition period and migration paths in the release notes.

## 🐛 Troubleshooting (FAQ)

- **Divergent toolchain / mathlib cache**  
  ```bash
  cp .lake/packages/mathlib/lean-toolchain ./lean-toolchain
  elan toolchain install "$(cat lean-toolchain)"
  lake update && lake exe cache get
  ```

- **Errors when trying to reexport with `export`/`open (...)` at the top**  
  Keep the entry point simple (only `import`); use qualified names
  `RoughBlocks.Light.*` in client modules.

- **`abbrev/def` aliases to `noncomputable` items**  
  Avoid “mirroring” Light symbols at the top of `RoughBlocks`, to prevent
  `dependsOnNoncomputable`/reducibility issues. Use qualified names instead.
